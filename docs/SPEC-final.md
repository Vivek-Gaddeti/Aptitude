## Shared data shapes

**Store** (`localStorage["apt:v1"]`, via `Store.load()`): `items` (keys below), `activity` (`"YYYY-MM-DD" → count`), `mocks` (array), `meta` (object).
- `q:<bankId>` / `g:<key>:<d>:<seed>`: `{ n, c, last, t, why, star, mark, note, status, level, next, … }` (written by `QB.record`).
- `pat:<sec>/<topic>/<pattern>`: `{ n, c, ts, seen }`. Learn topics: `<sec>:<topicId>` (DocPage status / SR).
- `meta.goal` (questions per day, default 25), `meta.daily` (`{ date, ids:[…], idx }`), `meta.speed` (`{ best: { <mode>: score } }`),
  `meta.fc` (flashcard SR: `{ "<cardKey>": { level, next, seen } }` — kept OUT of `items` so cards don't flood the header's due badge).
- `mocks[]`: `{ id: "m" + Date.now(), preset, name, at, seed, minutes, timeUsed, negative, score, max, acc, attempted, correct, wrong,
  secs: [{ title, sec, n, correct, wrong, skipped, score, max, time }], answers: [{ qid, sec, topic, pattern, chosen (or null), ok, secs, marked }] }`.

**Mock presets** (`data/mocks.js`): `window.MOCKS = [ { id, name, company, kind: "company"|"section"|"full", blurb, note,
minutes /* overall, or null when per-section */, negative /* marks lost per wrong, e.g. 0, 0.25, 1/3 */, marks: 1, sectionLock: bool, calculator: bool,
sections: [ { title, sec, topics: ["…"] | "all", count, minutes /* per-section timer or null */ } ] } ]`.
Preset ids are fixed (the strategy page links to `mock.html#start/<id>`): `tcs-nqt, infosys, wipro, accenture, cognizant, capgemini, hcl, tech-mahindra,
deloitte, amcat, elitmus, cocubes, quant-sectional, reasoning-sectional, verbal-sectional, di-sectional, full-mixed, quick-15`.
Company presets are "-style" practice formats (labelled *check the latest official pattern*), sized from public information about each test.

**Practice routes** (owned by PRACTICE+, used by others): `practice.html#daily` (daily set), `#speed` (60-second drill), `#qs/<id>,<id>,…`
(practise exactly these question ids; each id `encodeURIComponent`-ed), `#drill/<key>`, `#topic/<sec>/<topic>`, `#setup`, `#review`.

**Vocabulary** (`data/vocab.js`): `window.VOCAB = [ { w, pos, m /* meaning */, ex /* example sentence */, syn: [...], ant: [...] } ]` (~300 placement-level words).

**Flashcards**: formula cards come from `window.FORMULAS` (`data/formulas/*.js`: `{ sec, topic, title, items: [[name, formula, note]], tricks, traps }`),
card key `f:<topic>:<index>`; vocab card key `v:<word>`.

## Learn sections (LEARN-n agents)
Format = `docs/SPEC-stage1.md` §5, exactly like `data/learn/quant.js` (Percentages — read it fully, match its depth and voice):
`LEARN.<sec>.push({ id: <catalog topic id>, group: <catalog group>, title: <catalog title>, sub, tags, blocks })` and in the same file
`BRIEFS["<sec>:<topic>"] = "two short plain-English paragraphs";`. Topic shape: The idea → Formulas (or Rules) → Shortcuts → Patterns (one `["pattern", {...}]`
block per catalog pattern of the topic, key `sec/topic/pattern`, with spot / method / solved example / shortcut) → Common traps → Quick check
(`["quiz", [5 existing bank ids from data/q/<sec>/<topic>.js]]`). Extra blocks available: `["formulas", rows]`, `["table", head, rows]`,
`["tip"|"note"|"warn", text]`, `["chart", { type, labels, series:[{name,data}], unit }, caption]` (DI), `["html", svg]` (diagrams: inline SVG with
`stroke="currentColor"` / `fill="none"`, max-width ~420px). Every number in examples must be checked with node. Original text only.
The file starts with `window.LEARN = window.LEARN || {}; LEARN.<sec> = LEARN.<sec> || []; window.BRIEFS = window.BRIEFS || {};`.
