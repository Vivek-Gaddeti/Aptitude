# Aptitude Hub

An offline study site for placement aptitude tests. It covers Quantitative Aptitude, Logical Reasoning, Verbal Ability and Data Interpretation, with lessons, practice drills built on question generators, company-style mock tests, and revision tools (a mistake book, spaced repetition, flashcards) and a formula sheet. It is plain HTML, CSS and JavaScript with no build step and no server, so it works offline. Progress is saved in the browser (localStorage), and the dashboard has Export and Import for moving progress between browsers.

## Use it

- Live site: https://vivek-gaddeti.github.io/Aptitude/
- Or open `index.html` directly in a browser (file://).
- Settings (header button, or the tablet rail) has Layout (Auto, Desktop, Tablet) and Rail side (Left or Right) for the thumb rail on tablets.

## Working on it

After you add or change files under `data/` or `assets/`, run:

```
node tools/lite.js && python3 tools/pages.py && node tools/stamp.js
```

- `node tools/lite.js` rebuilds `data/progress.js` from the data files and prints the totals.
- `python3 tools/pages.py` writes every page from one template, so all pages load the same scripts in the same order.
- `node tools/stamp.js` adds a content fingerprint to each local script and stylesheet URL, so browsers do not mix an old cached file with a new one.

Check every question with:

```
node tools/verify.js
```

Use `node tools/verify.js --only <text>` to check only topics or patterns whose name contains the text (for example `--only percentages`). The check exits with code 1 if there are errors. Run it with 0 errors before every change is handed over.

Browser tests use `tools/cdp.js`. It opens the site as files in headless Chrome and runs a steps file you write. Set the `CHROME` environment variable to your Chrome or Chromium path if the script cannot find it. It needs Node 22 or later.

## Content rules

- Questions and lesson text are original. Do not copy text from books or websites.
- Every numeric answer is machine-checked. Questions carry a `calc` or `check` expression that `tools/verify.js` evaluates, and generated questions must produce a valid answer.
- Numbers use Indian digit grouping (for example 1,00,000), and decimals are shown only when the value is not a whole number.
